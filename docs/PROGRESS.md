**노트북/자동차 두 탭 → 필터 조건 선택 → FastAPI 호출 → PostgreSQL 조회 → 결과 목록/상세·정렬·페이지네이션 표시**.

## 4. 지금 알아야 할 문제와 결정

- **검증된 문제:** 현재 등록된 항목 없음. 다만 구현 상태 자체가 미확인이므로 "문제 없음"을 의미하지 않음.
- **고정 결정:** A안(Next.js + FastAPI + PostgreSQL 업무 테이블 2개), guest, SQL 필터 검색 우선, 필수 기능 전체 구현 후 통합 테스트.
- **데이터 주의:** 노트북 관측 최저가와 해당 구성 가격을 혼동하지 않음. 전기차 매물은 수집 당시 정보이며 실제 재고를 보장하지 않음.

## 5. 통합 담당자 갱신 절차 (2~5분 내)

1. 병합된 PR/커밋에서 **새로 가능한 사용자 동작**을 확인합니다.
2. 위 기능 표의 상태를 `코드 구현` 또는 실제 확인된 경우에만 `통합 확인`으로 변경합니다.
3. 최근 작업에 담당·날짜·PR 또는 커밋 링크를 한 줄 기록합니다.
4. 문제가 있으면 재현 방법과 영향만 적고, 해결되면 결과를 갱신합니다.
5. 다음 작업을 한 가지 구체적으로 지정합니다. 중요하지 않은 세부 구현은 나열하지 않습니다.
