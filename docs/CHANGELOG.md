# SpecFinder AI — 변경 이력

> **목적:** 사용자가 이해할 수 있는 제품 변화만 기록합니다. Git의 모든 파일 수정·커밋을 다시 적는 문서가 아닙니다.
> 갱신 책임: PR 병합 시 통합 담당자. 구현 확인 전에는 기능을 "추가됨"으로 기록하지 않습니다.

## [Unreleased] — MVP 개발 중

### 추가됨

- (실제 병합된 기능이 생기면 기록)

### 변경됨

- (사용자 동작이나 데이터 표시가 달라졌을 때 기록)

### 수정됨

- (재현된 오류가 수정되고 확인되었을 때 기록)

### 알려진 제한

- 현재 CSV는 수집 당시의 스냅샷입니다. 노트북 가격과 전기차 매물 상태는 실시간 정보를 보장하지 않습니다.
- AI 자연어 검색·LangGraph·RAG는 MVP 범위 밖입니다.

## 버전 기록 작성 예시 (아래는 템플릿이며 실제 구현 사실이 아닙니다)

```md
## [v0.1.0] — YYYY-MM-DD
### 추가됨
- 노트북 탭에서 제조사·RAM·가격으로 제품을 검색할 수 있게 됨. (PR #번호)
### 수정됨
- 검색 결과 0건일 때 이전 목록이 남는 오류를 수정함. (PR #번호)
### 알려진 제한
- 자동차 매물은 과거 수집본으로, 현재 판매 여부를 알 수 없음.
```

## 업데이트 규칙

- PR 1개마다 줄줄이 적을 필요 없이 **의미 있는 기능 변경**에만 추가합니다.
- `docs/PROGRESS.md`는 **현재 상태**, 이 파일은 **변화 이력**입니다.
- 변경 항목마다 가능하면 PR 링크 또는 커밋 SHA를 적습니다.
- 테스트하지 않은 수정은 "검증 완료"로 표현하지 않습니다.
- 문서용 변경은 필요할 때만 한 줄로 요약합니다.
